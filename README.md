# worldpress

Egyszerű, plugin alapú admin dashboard hozzáadva WordPress oldalhoz.

## Telepítés

1. Másold a `wp-content/plugins/worldpress-admin-dashboard` mappát a WordPress telepítésedbe.
2. Aktiváld a **WorldPress Admin Dashboard** plugint a WordPress admin felületen.
3. A bal oldali menüben nyisd meg: **WorldPress Dashboard**.
