Telepítési checklist – Ubuntu Server 26.04 LTS kisvállalati szerver

Verzió: v1
Dátum: 2026-06-09
Cél: letölthető, külön telepítési lista a rendszerterv mellé

Ez a dokumentum a rendszerterv-ubuntu-kisvallalati-szerver.html mellé készült külön, letölthető telepítési checklistként.

1. Kiinduló adatok

ElemÉrték
Operációs rendszerUbuntu Server 26.04 LTS

2. Előkészítés

  • [ ] Ubuntu Server 26.04 LTS telepítő elkészítve
  • [ ] 4 SSD fizikailag beszerelve
  • [ ] publikus NIC csatlakoztatva
  • [ ] belső NIC csatlakoztatva
  • [ ] BIOS/UEFI: UEFI boot bekapcsolva
  • [ ] SATA mód: AHCI
  • [ ] alaplapi fake RAID kikapcsolva / nem használva

3. Telepítés közbeni storage célkép

  • [ ] SSD1 + SSD2 → rendszer RAID1
  • [ ] SSD3 + SSD4 → adat RAID1
  • [ ] EFI partíció mindkét rendszerlemezen
  • [ ] rendszer tömbön: /, /var, /opt
  • [ ] adat tömbön: /srv
  • [ ] swapfile használata külön swap partíció helyett

4. Első boot utáni ellenőrzés

ip a
ip r
hostnamectl
timedatectl
lsblk
cat /proc/mdstat
df -h
  • [ ] mindkét NIC látszik
  • [ ] RAID tömbök összeálltak
  • [ ] mountpontok helyesek

5. Netplan véglegesítés

network:
  version: 2
  renderer: networkd

  ethernets:
    enp1s0:
      dhcp4: false
      addresses:
        - 195.199.215.1/29
      routes:
        - to: default
          via: 195.199.215.6
      nameservers:
        addresses:
          - 195.199.255.57
          - 195.199.255.58

    enp2s0:
      dhcp4: false
      addresses:
        - 10.1.200.10/16
sudo nano /etc/netplan/01-server.yaml
sudo netplan generate
sudo netplan try
sudo netplan apply
ip a
ip r
resolvectl status
  • [ ] publikus IP működik
  • [ ] default route a publikus NIC-en van
  • [ ] belső IP működik
  • [ ] DNS feloldás működik

7. SSH hardening

sudo nano /etc/ssh/sshd_config
PermitRootLogin no
PasswordAuthentication no
PubkeyAuthentication yes
ListenAddress 10.1.200.10
sudo systemctl restart ssh
sudo systemctl status ssh
  • [ ] kulcsos SSH belépés működik
  • [ ] root login tiltva
  • [ ] jelszavas login tiltva

8. Tűzfal

sudo ufw default deny incoming
sudo ufw default allow outgoing

sudo ufw allow 80/tcp
sudo ufw allow 443/tcp

sudo ufw allow from 10.1.0.0/16 to any port 22 proto tcp
sudo ufw allow from 10.1.0.0/16 to any port 139 proto tcp
sudo ufw allow from 10.1.0.0/16 to any port 445 proto tcp
sudo ufw allow from 10.1.0.0/16 to any port 10000 proto tcp

sudo ufw enable
sudo ufw status verbose
  • [ ] 80/443 publikus
  • [ ] 22/139/445/10000 csak belső hálóról
  • [ ] UFW aktív

9. Apache + PHP-FPM

sudo a2enmod ssl headers rewrite proxy proxy_http proxy_fcgi setenvif auth_basic
sudo systemctl restart apache2
sudo mkdir -p /srv/www/wordpress
sudo mkdir -p /srv/www/app1
sudo mkdir -p /srv/www/app2
sudo mkdir -p /opt/apps/app1
sudo mkdir -p /opt/apps/app2

14. Webmin

A Webmin telepítését a hivatalos Webmin repository alapján érdemes elvégezni. A terv szerint csak a belső hálózatról lesz elérhető a 10000/tcp porton.
  • [ ] Webmin telepítve
  • [ ] csak belső hálóról elérhető

15. Backup

sudo mkdir -p /srv/backup/daily
sudo mkdir -p /srv/backup/restic

export RESTIC_REPOSITORY=/srv/backup/restic
export RESTIC_PASSWORD='eros-jelszo'
restic init
restic backup /etc /srv/www /srv/data /srv/share /opt/apps
restic snapshots
mysqldump --single-transaction --routines --events --databases wordpress_db app1_db app2_db > /srv/backup/daily/db-$(date +%F).sql
  • [ ] restic inicializálva
  • [ ] első backup lefutott
  • [ ] DB dump működik
